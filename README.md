# Farbod Bigdeli

Backend engineer and Computer Science PhD student at the University of Texas at Arlington.

I've spent 4+ years building Go and Python services in production: microservices, API gateways, caching layers and search. At SnappFood, Iran's largest food-delivery platform, I built Go APIs for new microservices and a Redis caching service that cut database load by 70%. My research focuses on reliable software and careful ML evaluation.

I'm open to backend, platform and AI engineering internships.
